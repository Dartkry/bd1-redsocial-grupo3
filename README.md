# Red Social Pascualina - Modelo Conceptual

**Nombre del proyecto:** Diseño de Base de Datos para Red Social Estudiantil (Red Social Pascualina)

**Integrantes del equipo:** 
- Daniel Grisales

## Breve descripción del caso
Este proyecto presenta el modelo conceptual (Modelo Entidad-Relación) diseñado para soportar una nueva red social enfocada en la comunidad educativa. El objetivo principal es resolver la falta de espacios para la conexión casual, el intercambio de conocimientos y la formación de grupos de estudio en la virtualidad. La plataforma permite a los estudiantes crear perfiles, conectar con compañeros, publicar actualizaciones, organizar grupos y programar eventos.
